# Firmware

ESP32 firmware files have not been added yet. Put the sketch here (for example `concentrator/concentrator.ino`) together with the pin map for the relay module, motor driver and flow sensors.

The sequence it implements is described in the top-level README (fill, settle, drain, backflush, dose), and the adjustable times (fill, backflush, dosing, valve delay) are set from the web interface.
