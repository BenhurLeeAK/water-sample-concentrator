# CAD files (STL) for the 3D-printed parts

These are the printable parts of the microscope module and flow-cell holder described in the paper.

| File | Part | Approx. size (mm) |
|---|---|---|
| `focus-threadv3.stl` | Helical focuser body (threaded focusing tube) | 52 x 52 x 80 |
| `base-microscopy.stl` | Microscope base | 100 x 62 x 119 |
| `attachment-flow-cell--flow-slide.stl` | Open-top slider that carries the flow cell | 50 x 37.7 x 85 |
| `baseextension.stl` | Base extension plate | 150 x 5 x 217 |

Print settings used in the paper: black PLA. Check fit and tolerances on your own printer before use.
