# CAD files

The 3D-print files for the helical focuser, collet, RMS adapter, base and slider have not been added yet. Put the STL (and source CAD) files here.

Print settings used: black PLA, 0.4 mm nozzle, 0.2 mm layer height, 30% infill, no supports, thread tolerance variant 0.37 mm per side.

The focuser is derived from the Hadley telescope focuser on Printables (models 224383 and 265768); check those licences before redistributing derived files.
